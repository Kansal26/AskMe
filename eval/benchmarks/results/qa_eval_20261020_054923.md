| Question ID | Question | v1 SQL (Passed) | v2 SQL (Failed) | Diff Summary | Root Cause |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `q01` | What is our total net revenue? | `SELECT SUM(net_amount) AS total_net_reve...` | `SELECT 'Total Net Revenue' AS metric, SU...` | Agent projected ['metric', 'value'] instead of ['total_net_revenue']. | Prompt v2 instructed the agent to strictly follow corporate metric definitions. The model formatted its response as a key-value metric report ('Total Net Revenue' AS metric, SUM(net_amount) AS value) instead of a scalar projection, causing column name mismatch. |
| `q06` | How many orders were placed through Amazon? | `SELECT COUNT(DISTINCT order_id) AS amazo...` | `SELECT channel, COUNT(DISTINCT order_id)...` | Agent projected ['channel', 'order_count'] instead of scalar ['amazon_order_count']. | Prompt v2 emphasized schema dimensions for aggregations. The model included the 'channel' column in the GROUP BY and SELECT clause even when filtered to a single constant ('Amazon'). |
